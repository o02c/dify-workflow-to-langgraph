# LangGraph Style Guide

This document defines the coding conventions and patterns for LangGraph workflows generated by dify2langgraph.

## State Management Convention

### TypedDict for State

Use `TypedDict` with `total=False` for optional fields:

```python
from typing import TypedDict

class NodeOutput(TypedDict, total=False):
    """Use TypedDict with total=False for optional fields."""
    text: str
    error: str | None

class GraphState(TypedDict, total=False):
    """Main graph state - each key is a node's output."""
    node_name: NodeOutput
```

### State Key Naming

- Use `snake_case` for state keys (matching function names)
- Each node stores its output under its own key
- Access other nodes' outputs via `state["other_node"]["field"]`

## Node Function Convention

### Function Signature

```python
from langgraph.types import Command

def node_function(state: GraphState) -> Command:
    """
    1. Accept GraphState as input
    2. Return Command with partial state update
    3. Be pure functions where possible
    """
    input_value = state["previous_node"]["field"]
    result = process(input_value)
    return Command(update={"this_node": {"output": result}})
```

### Node Function Guidelines

1. **Single Responsibility**: Each node should do one thing well
2. **Pure Functions**: Avoid side effects when possible
3. **Error Handling**: Catch exceptions and return error states
4. **Logging**: Use the configured logger, not print statements

### Example Implementation

```python
from dify2langgraph.logging_config import get_logger
from langgraph.types import Command

logger = get_logger(__name__)

def process_data(state: GraphState) -> Command:
    """Process input data and return results.

    Args:
        state: Current graph state.

    Returns:
        Command with state update.
    """
    try:
        input_text = state["start"]["text"]
        result = transform(input_text)

        output: ProcessDataOutput = {
            "result": result,
            "error": None,
        }
    except Exception as e:
        logger.error("Processing failed: %s", e)
        output = {
            "result": None,
            "error": str(e),
        }

    return Command(update={"process_data": output})
```

## Conditional Edge Convention

### Router Functions

```python
def route_condition(state: GraphState) -> str:
    """Return string matching edge labels, deterministic."""
    if state["classifier"]["selected_branch"] == "a":
        return "branch_a"
    return "branch_b"
```

### Guidelines

1. **Deterministic**: Same input should always produce same output
2. **Return Strings**: Must match edge labels exactly
3. **No Side Effects**: Only read from state, never write

## Graph Construction Convention

### Standard Pattern

```python
from langgraph.graph import END, START, StateGraph

def build_graph():
    """Build and return the compiled workflow graph."""
    graph = StateGraph(GraphState)

    # Add nodes
    graph.add_node("node_a", node_a_function)
    graph.add_node("node_b", node_b_function)

    # Add edges
    graph.add_edge(START, "node_a")
    graph.add_edge("node_a", "node_b")
    graph.add_edge("node_b", END)

    return graph.compile()
```

### Conditional Edges

```python
graph.add_conditional_edges(
    "classifier",
    route_condition,
    {
        "branch_a": "handler_a",
        "branch_b": "handler_b",
    },
)
```

## LLM Node Pattern

### Using LangChain Models

```python
from langchain_core.messages import HumanMessage, SystemMessage

def llm_node(state: GraphState) -> Command:
    """Execute LLM inference."""
    from llm import get_chat_model

    llm = get_chat_model()

    messages = [
        SystemMessage(content="You are a helpful assistant."),
        HumanMessage(content=state["start"]["query"]),
    ]

    response = llm.invoke(messages)

    output: LlmNodeOutput = {
        "text": response.content,
        "usage": response.usage_metadata or {},
    }

    return Command(update={"llm_node": output})
```

## File Organization

### Generated Output Structure

A self-contained package with relative imports (ADR-0007), run via
`python -m <package>` from the parent directory:

```
output/workflow/       # a Python package (dir name must be a valid identifier)
├── __init__.py        # Re-exports build_graph
├── __main__.py        # Run entry point (python -m workflow)
├── state.py           # GraphState and node output TypedDicts
├── graph.py           # Graph construction and compilation
├── llm.py             # LLM configuration (copied from templates)
└── nodes/
    ├── __init__.py    # Re-exports all node functions
    ├── start.py       # Start node
    ├── process.py     # Processing nodes
    └── end.py         # End node
```

## Import Convention

### Standard Imports

```python
# Standard library
import json
from pathlib import Path

# Third-party
from langchain_core.messages import HumanMessage
from langgraph.types import Command

# Local (relative, within the generated package -- ADR-0007)
from ..state import GraphState, NodeOutput  # in nodes/*.py
# from .state import GraphState             # in graph.py
```

## Logging Convention

### Use Structured Logging

```python
from dify2langgraph.logging_config import get_logger

logger = get_logger(__name__)

# Good
logger.info("Processing node: %s", node_id)
logger.error("Failed to process: %s", error)

# Bad - don't use print
print(f"Processing node: {node_id}")  # Don't do this
```

## Testing Convention

### Unit Test Structure

```python
def test_node_function_success():
    """Test node with valid input."""
    state = {"input_node": {"value": "test"}}
    result = node_function(state)

    assert "node_function" in result.update
    assert result.update["node_function"]["output"] == "expected"

def test_node_function_error():
    """Test node with invalid input."""
    state = {"input_node": {"value": None}}
    result = node_function(state)

    assert result.update["node_function"]["error"] is not None
```
